# Security Policy

Provenance handles resumes and other sensitive personal data. Security is the top priority in this project's ordering of concerns.

## Reporting a vulnerability

Do not open a public issue. Email the maintainer (address will be added before first public release) with reproduction steps. Expect an acknowledgement within 7 days.
